# 드론 열화상 감시 영상 전송 시뮬레이터

전기공학과 전력 ICT 수업 발표에서 시연하는 인터랙티브 시뮬레이터입니다.
주제는 송·배전 설비 드론 열화상 감시에서의 영상 압축(HEVC)과 QoS 제어이며, 교재 Chapter 09 '멀티미디어 통신과 미디어'와 연결됩니다.

- `index.html` 한 파일에 HTML, CSS, JavaScript가 모두 들어 있습니다.
- 외부 이미지, 라이브러리, 인터넷 연결 없이 Canvas로 직접 그립니다.
- 화면의 모든 수치는 발표용 예시 값입니다.

## 실행 방법

`index.html`을 더블클릭해서 Chrome이나 Edge로 열면 됩니다. 별도 설치가 필요 없습니다.

| 단축키 | 동작 |
|---|---|
| `Space` | 일시정지 / 다시 재생 |
| `1` `2` `3` | 코덱 RAW / H.264 / HEVC |
| `B` | 프레임 블록 분석 켜기·끄기 |
| `E` | 긴급 경보 발생 |
| `Q` | QoS 우선순위 제어 켜기·끄기 |

## 발표 설명 포인트

### 섹션 A · 드론 열화상 화면과 코덱 압축 (교재 2절 · 압축 기술)

1. 무압축 RAW는 약 120 Mbps가 필요해 드론 무선 링크(10~50 Mbps)로는 보낼 수 없습니다. H.264는 약 16.7 Mbps, HEVC는 그 절반인 약 8.3 Mbps로 같은 장면을 보냅니다.
2. GOP 표시줄에서 I 프레임은 화면 전체를, P·B 프레임은 앞뒤 화면과 달라진 부분만 보냅니다. 그래서 I 프레임 때 데이터가 몰립니다.
3. '프레임 블록 분석'을 켜면, 드론 이동은 움직임 벡터로 보상되고 깜빡이는 열점, 지나가는 차량, 새로 들어온 가장자리 블록만 전송됩니다. 정지 배경 블록은 90% 이상 생략됩니다.

### 섹션 B · 전송과 QoS (교재 1절 · QoS)

1. 무선 구간이 병목입니다. 영상이 링크보다 크거나 I 프레임이 몰려 들어오면 드론 송신 큐가 쌓이고, 큐가 넘친 패킷은 버려집니다. 그래서 관제 화면이 멈추거나 깨집니다.
2. 대역폭이 같을 때 H.264가 HEVC보다 먼저 멈춥니다. 예를 들어 '보통 20 Mbps'에서 H.264는 I 프레임마다 멈칫하지만 HEVC는 끊김이 없습니다. 압축 효율이 곧 전송 품질입니다.
3. QoS OFF(FIFO)에서는 경보 패킷이 영상 패킷 뒤에 줄을 서서 약 1.8초 늦게 도착하거나 아예 버려집니다. QoS ON에서는 경보가 우선 차선으로 앞질러 약 0.05초 만에 도착합니다. 다만 영상 끊김은 그대로이므로, QoS는 대역폭을 늘려 주는 기술이 아니라 중요한 데이터를 먼저 보내는 기술입니다.

## 시뮬레이션 모델 (예시 값)

| 항목 | 값 |
|---|---|
| 코덱별 비트레이트 | RAW 120, H.264 16.7, HEVC 8.3 Mbps |
| 링크 대역폭 | 낮음 10, 보통 20, 높음 50 Mbps |
| 프레임 간격 | 0.4초 (실제 30fps를 눈으로 따라갈 수 있게 늘림) |
| GOP | I P B B P B B P, 크기 비율 I 2.6 : P 1.0 : B 0.6 |
| 패킷 | 화면의 점 1개 = 영상 0.5 Mb, 경보 패킷은 그 2% 크기 |
| 송신 큐 | 최대 40개, 넘치면 버림. QoS ON이면 경보 전용 큐 10개 추가 |
| 관제 화면 | 생성 후 0.5초 안에 다 오지 않으면 멈춤, 1.5초가 넘으면 그 프레임을 포기(깨짐) |
| 경보 허용 지연 | 200 ms 이하 초록, 초과 빨강 |

- 전송 지연 = 큐 대기 시간 + 전송 시간(패킷 크기 ÷ 대역폭) + 전파 지연 30 ms
- 패킷이 빠진 프레임은 다음 온전한 I 프레임이 올 때까지 깨진 화면으로 남습니다(P·B 프레임이 앞 화면을 참조하기 때문).
